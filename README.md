## About

I'm a full stack engineer with 10+ years of experience building web applications, currently holding architectural responsibility for **SIMATIC IPC ORCLA** at Siemens, an orchestration platform for setting up, commissioning, updating and maintaining industrial PCs.

Lately my focus is applying LLMs and agentic workflows to everyday engineering work: code review, root-cause analysis, dependency security and developer productivity. I also run internal trainings so that teams spend less time on routine tasks.

## What I work on

- **Software architecture:** architectural ownership of ORCLA (device health, firmware, security policies, OS imaging).
- **Full stack development:** React / TypeScript frontends and Spring Boot services, CI/CD, and cloud operations at 99.9% availability.
- **AI-assisted engineering:** internal tools built on Azure OpenAI, RAG and MCP, plus company guidelines for using LLMs in development.
